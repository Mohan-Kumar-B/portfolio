# 🚀 How This Website Was Built & Deployed

This project was created and published using the following workflow:

```text
Lovable AI
     ↓
  VS Code
     ↓
GitHub Desktop
     ↓
   GitHub
     ↓
  Netlify
     ↓
🌍 LIVE WEBSITE
```

## 🔄 Development & Deployment Process

### 1. 🤖 Lovable AI — Build the Website

The website was initially created with the help of **Lovable AI**.

Lovable AI was used to generate the initial website structure, components, styling, and functionality.

```text
Idea / Prompt
     ↓
Lovable AI
     ↓
Initial Website
```

---

### 2. 💻 VS Code — Edit & Customize

The project was then opened in **Visual Studio Code (VS Code)**.

VS Code was used to:

* Edit the website code
* Customize the design
* Add or modify sections
* Fix errors
* Add images and files
* Test changes locally

```text
Lovable Project
      ↓
    VS Code
      ↓
Edited & Improved Website
```

---

### 3. 🖥️ GitHub Desktop — Upload Changes

After making changes in VS Code, **GitHub Desktop** was used to manage the project and upload the changes.

GitHub Desktop makes it easier to:

* Track changes
* Commit changes
* Push changes to GitHub

```text
VS Code
   ↓
GitHub Desktop
   ↓
Commit Changes
   ↓
Push Changes
```

---

### 4. 🐙 GitHub — Store the Project

The project code is stored in a **GitHub repository**.

GitHub acts as the online home for the project's source code.

```text
GitHub Desktop
      ↓
    GitHub
      ↓
Repository
```

Whenever new changes are pushed to GitHub, the repository is updated.

---

### 5. 🌐 Netlify — Deploy the Website

**Netlify** is connected to the GitHub repository.

Netlify takes the website code from GitHub and deploys it to the internet.

```text
GitHub Repository
       ↓
     Netlify
       ↓
   Build & Deploy
```

After deployment, Netlify provides a public website URL.

---

## 🌍 Final Result

The complete workflow is:

```text
🤖 Lovable AI
      ↓
💻 VS Code
      ↓
🖥️ GitHub Desktop
      ↓
🐙 GitHub
      ↓
🌐 Netlify
      ↓
🚀 LIVE WEBSITE
```

### 🔁 Updating the Website

When changes are needed:

```text
Edit in VS Code
      ↓
Commit in GitHub Desktop
      ↓
Push to GitHub
      ↓
Netlify detects the changes
      ↓
Website is automatically redeployed
      ↓
🌍 Updated Live Website
```

This makes it easy to continuously improve the website without manually uploading the website files every time.
